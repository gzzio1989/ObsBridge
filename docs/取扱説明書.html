Syncroom OBS Bridge v1.0.0 取扱説明書

DAW（ASIO / CoreAudio）のマスタートラック音声を、遅延ゼロのまま OBS Studio 等の配信ソフトへ送るブリッジプラグイン

1. このプラグインでできること

  • REAPER / Cubase / Studio One / Logic Pro などの ASIO（またはCoreAudio）出力を一切邪魔せず（追加遅延 0.0 ms）、同じミックス音を仮想オーディオドライバへ同時に流し込みます。
  • DAWの Masterトラックで syncroom_vst_bridge2 の「下（後段）」 に挿すだけで、自分のボーカル・楽器音 ＋ SYNCROOMの他のメンバー全員の音 がそのままOBSに入ります。
  • DAW側（例：48000 Hz）と仮想ドライバ側（例：44100 Hz）のサンプルレートが違っていても、内蔵の自動リサンプラ＆クロックずれ吸収エンジンにより、プツプツ音なしで長時間安定送信します。

2. インストール方法

Windows 10 / 11 (64-bit)

  • インストーラー版（推奨）：SyncroomOBSBridge_Setup_v1.0.0.exe をダブルクリックして実行すると、標準VST3フォルダへ自動配置されます（VC++ランタイム等の追加導入は不要です）。
  • ZIPポータブル版：展開した中にある Syncroom OBS Bridge.vst3 フォルダごと、C:\Program Files\Common Files\VST3\ へコピーしてください。
  • 必要な仮想ドライバ：SYNCROOM2 導入済みなら最初から入っている Yamaha SYNCROOM Driver (WDM) を自動検出します。SYNCROOM未導入のPCでは無料の VB-CABLE 等を入れるだけで自動認識します。

macOS (macOS 11 Big Sur 以降 / Apple Silicon M1〜M4 & Intel 両対応)

  • 必要な仮想ドライバ（初回のみ）：Mac版SYNCROOMには仮想ドライバが同梱されないため、無料の BlackHole 2ch などを入れておくと自動で接続されます。
  • VST3版（REAPER / Cubase / Studio One / Ableton Live 等）：Syncroom OBS Bridge.vst3 を /Library/Audio/Plug-Ins/VST3/ にコピーします。
  • AU版（Logic Pro / GarageBand 等）：Syncroom OBS Bridge.component を /Library/Audio/Plug-Ins/Components/ にコピーします。

3. かんたん3ステップ設定（DAW ＆ OBS）

  1. DAWのMasterトラックを開く
    MasterトラックのFXチェーンで、syncroom_vst_bridge2 の すぐ下（後段） に Syncroom OBS Bridge を追加します。
    （※SYNCROOMを使わずDAW単体の音をOBSへ送りたい場合も、Masterトラックの一番最後に挿してください）
  2. 緑ランプの点灯を確認する
    プラグイン画面に緑色の丸ランプと 送信中: ライン (Yamaha SYNCROOM Driver (WDM))（Macでは BlackHole 2ch 等）が表示されれば送信開始されています。
  3. OBS Studio の音声設定で選ぶ
    OBSの 設定 → 音声 で、マイク/補助音声（または音声入力キャプチャ）に 同じ仮想ドライバ名（Windowsなら ライン (Yamaha SYNCROOM Driver (WDM))、Macなら BlackHole 2ch）を選択します。
⚠️ ワンポイント注意：
ボーカルトラック単体や、Masterトラックの syncroom_vst_bridge2 より「上（前段）」に挿すと自分の声だけがOBSに送られます。SYNCROOMの他のメンバー全員の音もOBSに入れるには、必ず Masterトラックの syncroom_vst_bridge2 の「下（後段）」に挿してください。
