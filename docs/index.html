Syncroom OBS Bridge v1.0.0

DAW（ASIO / CoreAudio）の超低遅延モニター（追加遅延 0.0 ms）はそのまま、
自分の歌声・楽器 ＋ SYNCROOM他メンバー全員の音 を OBS Studio へ直接流し込むブリッジプラグイン。

⬇ Windows インストーラー版 (.exe) Windows 10 / 11 (64-bit) 推奨・ワンクリック導入 ⬇ Windows ポータブル版 (.zip) VST3手動コピー用・ランタイム不要 ⬇ macOS Universal 版 (.zip) Apple Silicon & Intel 対応 (VST3 + Logic用AU)

かんたん3ステップの使い方

  1. インストールする
    Windowsは .exe を実行するだけ。Macは .vst3（Logic Proは .component）をプラグインフォルダへ入れます（Macは無料の BlackHole 2ch 導入を推奨）。
  2. DAWのMasterトラック（syncroom_vst_bridge2 の下）に挿す
    MasterトラックのFXチェーンで syncroom_vst_bridge2 の下（後段）に追加すると、自動で Yamaha SYNCROOM Driver（または VB-CABLE / BlackHole）へ送信が始まります。
  3. OBSの音声設定で選ぶ
    OBSの「設定 → 音声」のマイク/補助音声で ライン (Yamaha SYNCROOM Driver (WDM))（Macは BlackHole 2ch）を選べばそのままメーターが振れます！
💡 ポイント： syncroom_vst_bridge2 の「下（後段）」に挿すことで、自分の声だけでなく SYNCROOMルーム内の他のメンバー全員の音 もまとめてOBSに入ります。48kHz⇄44.1kHzのレート差も自動で滑らかに変換します。

主な特徴

  • 本線ASIOの追加遅延 0.0 ms：ロックフリー転送のため、ヘッドホンモニターやオーディオIF側のレイテンシ・プツプツに一切影響しません。
  • サンプルレート＆クロックずれ自動吸収：DAWが48000Hz・ドライバ側が44100Hzのままでも、設定変更なしで長時間ノイズレスに送信します。
  • OBS側だけ独立ミュート＆音量調整：ヘッドホンのモニター音は止めずに、OBS配信側への送信音量調整・一時ミュートが可能です。
